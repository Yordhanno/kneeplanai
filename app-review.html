Quick review steps

Pasos rápidos para la revisión

  1. Launch KneePlanAI Standard.
  2. Select Open radiograph and open the downloaded DICOM file.
  3. Select the right side.
  4. Place or adjust the anatomical landmarks and joint lines.
  5. Open Results, Report, and Analysis.
  6. Select Sources in the main toolbar to view the scientific methodology and linked citations.
  1. Abra KneePlanAI Standard.
  2. Seleccione Abrir radiografía y abra el archivo DICOM descargado.
  3. Seleccione el lado derecho.
  4. Coloque o ajuste las referencias anatómicas y las líneas articulares.
  5. Abra Resultados, Informe y Análisis.
  6. Seleccione Fuentes en la barra principal para consultar la metodología científica y las referencias enlazadas.
